Campaigns App simplifies and accelerates the deployment of custom marketing funnels and checkouts with Next Commerce's Campaigns API.

<Callout type="success" title="Preparing to Go Live?">

Add each launch domain to the Campaigns App allowlist and mark production traffic as **Production**. Development domains can accept live orders, but analytics tracking events are not recorded for them.

</Callout>

Campaigns App appears in the dashboard sidebar on new stores. If it is missing, install it from the **Apps** menu.

## Custom Funnels with Campaigns API

Next Commerce supports fully custom marketing funnels, including checkouts and post-purchase upsells. The server-side API method for creating fully custom flows is to use the [Admin API](https://developers.nextcommerce.com/docs/admin-api/guides/external-checkout) with a server-to-server connection.

With **Campaigns App**, there is no need for server-to-server backend API integration. The Campaigns App uses a frontend CORS-enabled API to allow custom funnels without a backend integration.

<Callout type="info">

Developers can use the pre-built [Campaign Cart SDK](https://developers.nextcommerce.com/docs/campaigns/cart-system) and [Campaign Page Kit](https://developers.nextcommerce.com/docs/campaigns/page-kit) starter templates to accelerate custom marketing funnel development in Campaigns App.

</Callout>

Learn more about the [NEXT Campaigns API](https://developers.nextcommerce.com/docs/campaigns/api) and the best practices for creating and deploying fully custom customer experiences.

## Set Up a Campaign

A campaign can take orders after two steps:

1. **Create the campaign** - name, currency, language, shipping, and payments. See [Create a Campaign](#create-a-campaign) below.
2. **Create its offers** - choose the store products the funnel sells and the discount for each quantity tier. Selecting products in an offer adds them to the campaign, so there is no separate product setup step. See [Campaigns Offers & Discounts](/docs/apps/campaigns-app/campaigns-offers-and-discounts).

Then allow the funnel's domains under Campaigns App **Settings**, and give your developer the campaign's API key from **Developer**.

## Configure Campaigns App

Open **Campaigns App** from the dashboard sidebar.

From the Campaigns App sidebar, select **Settings**.

* Select **Add Domain** to whitelist a domain for your custom marketing funnel.
* Specify the domain's **Environment** - whether it should be used for **Development** or **Production**.

Both domain types accept live orders, but analytics tracking events are not recorded on Development domains.

<Callout type="warn">

Campaigns API requires that all API calls are made from a whitelisted domain for security purposes.

</Callout>

## Create a Campaign

From the **Campaigns App** main workspace, select **New Campaign** and fill in the form.

**Campaign**

* **Name** - the internal reference name for your campaign.
* **Default Currency** - the base currency for the campaign. It can't be changed after the campaign is created.
* **Additional Currencies** - optionally add more currencies for multi-geo campaigns. Prices in these currencies are converted from the default currency.
* **Language** - select from the languages enabled on the store.

**Shipping**

The table lists the [shipping methods](/docs/start-here/get-started/fulfillment-settings#shipping-methods) set up on your store.

* Tick **Enabled** for each method the campaign checkout should offer. At least one method must be enabled.
* **Campaign Price** starts at the method's **Store Price**. Change it to charge a different rate on this campaign, for example a flat rate or free shipping.
* Choose the **Default** method.
* **Available Shipping Countries** - the countries customers can ship to. The list only includes countries the enabled methods cover.

To discount shipping only when an order qualifies, keep the campaign price and create a shipping [offer](/docs/apps/campaigns-app/campaigns-offers-and-discounts).

<Callout type="info">

If the table is empty, create a shipping method and price in your store's [Fulfillment Settings](/docs/start-here/get-started/fulfillment-settings#set-up-shipping-methods) first. Multi-currency campaigns need a store shipping price in every currency they sell in.

</Callout>

**Payments**

* **Payment Gateway Group** - the store's default [gateway group](/docs/features/payments#gateway-groups) is preselected. Choose another group to route this campaign's payments differently.
* **Payment Methods** - the payment methods accepted on the campaign checkout.
* **Express Payment Methods** - the express buttons (PayPal, Apple Pay, Google Pay) shown above the checkout form.

Select **Create Campaign**, then open the campaign's **Offers** tab and select **Add Offer**.

### Campaign Settings

Open a campaign and select **Settings** to change the values above, plus:

* **Recalculate Prices for All Currencies** - shown on multi-currency campaigns when you change a shipping price; converts the new price into the other currencies.
* **PayPal Account** - assign a PayPal account to the campaign, or leave blank to use the store's [default PayPal account.](/docs/features/payments/paypal#configure-paypal)
* **Statement Descriptor** - define a custom descriptor to appear on your customer's card statement for your campaign (for payment gateways supporting dynamic descriptors only).
* **Enable Package Retail Price & Quantity** - shown under **Advanced** only on older campaigns that use package-level Retail Price or Quantity. Set every product's quantity to 1 before turning it off. New campaigns use [Offers & Discounts](/docs/apps/campaigns-app/campaigns-offers-and-discounts) for quantity pricing and savings.

### Campaign Workspace

Open a campaign to work from its tabs:

* **Analytics** - sessions, carts, orders, and conversion for the campaign. See [Campaign Analytics](/docs/apps/campaigns-app/campaign-analytics).
* **Offers** - the campaign's offers and discount codes, with a price preview. See [Campaigns Offers & Discounts](/docs/apps/campaigns-app/campaigns-offers-and-discounts).
* **Products** - the products the campaign sells and their campaign names, prices, and images. See [Campaign Products](/docs/apps/campaigns-app/build-campaign-packages).
* **Settings** - the campaign's currencies, shipping, and payments.

Use **More Actions** to **Clone** or **Delete** the campaign.

Use the campaign's **Developer** workspace for:

* installation details
* Campaigns API context
* session tracking setup
* campaign request logs

### Campaigns App Logs

Open **Developer** from a campaign, then use the **Logs** section to inspect that campaign's recent Campaigns API requests and responses. To investigate activity across campaigns, select **Logs** from the Campaigns App submenu.

Logs are filterable by the following factors to help with debugging and performance analysis:

* API Method
* Campaign
* Payment Method
* Referrer
* Date created from/to
* Email Address
* Status (Success / Failed)

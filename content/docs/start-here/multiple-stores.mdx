---
title: "Managing Multiple Stores"
description: "Switch between store dashboards and manage team access across stores"
---
NEXT uses single sign-on (SSO), so one account can be granted Dashboard access to multiple stores. Use the same email address for each store you work with. Your access and permissions are set separately for each store.

## Switch Stores from the Dashboard

1. Select the current store's name or icon at the top of the Dashboard sidebar to open **Switch Store**.
2. Find the store you want to open. Use the search field to search by store name if needed.
3. Select that store to open its Dashboard.

The current store is labeled **Current** in the switcher. After switching, check the store name before making changes or working with orders.

## Open a Store from Your NEXT Account

You can also choose a store from the [NEXT Accounts portal](https://accounts.29next.com/):

1. Sign in with the email address used for your store access.
2. Choose **Stores** to see the stores available to your account.
3. Choose **Dashboard** next to the store you want to open.

## Team Access Across Stores

A store administrator grants access from **Settings > Users & Permissions** in each store. Ask the administrator to use the same email address when adding you to another store, so you can access it through your existing NEXT account.

Roles and permissions apply to the individual store. For example, you can have full admin access in one store and a limited set of permissions in another. Switching stores uses the permissions assigned to you in the destination store.

See [Invite Team Members](/docs/start-here/get-started/invite-team-members) for adding Dashboard users and setting up Permission Groups.

## If a Store Is Missing

Check that you are signed in with the email address that was granted access to the store. If it still does not appear in the switcher or Accounts portal, ask a store administrator to confirm your access and that the store is active.

Apple Pay is supported as a payment method on the Next Commerce Storefront Checkout and over the [**Admin API**](https://developers.nextcommerce.com/docs/admin-api/guides/apple-pay).  Apple Pay allows customers using iOS, iPad, or Mac devices to securely and conveniently complete payments with a single tap.

Apple Pay is supported on the following gateways:

| Gateway | Notes |
| --- | --- |
| [NEXT Payments](/docs/features/payments/gateways/next-payments) | |
| [Adyen](/docs/features/payments/gateways/adyen) | |
| [Airwallex](/docs/features/payments/gateways/airwallex) | Recurring billing may not be supported |
| [Authorize.net](/docs/features/payments/gateways/authorize-net) | Recurring billing may not be supported |
| [Braintree](/docs/features/payments/gateways/braintree) | |
| [Checkout.com](/docs/features/payments/gateways/checkout-com) | |
| [NMI](/docs/features/payments/gateways/nmi) | |
| [Paysafe](/docs/features/payments/gateways/paysafe) | Recurring billing may not be supported |
| [Stripe Payment Intents](/docs/features/payments/gateways/stripe-payment-intents) | |
| [Test Gateway](/docs/features/payments/gateways/test-gateway) | |

Contact support to confirm Apple Pay recurring billing on the gateways marked above.

## Add Apple Pay to a Gateway

When you've added a supported payment gateway, enabling Apple Pay is simple:

* From the **Settings > Payments** view, choose a gateway ID
* On the Gateway Detail view, under **Apple Pay,** click **Enable**

<Callout type="info">

Apple Pay registers your store's [**primary domain**](/docs/start-here/get-started/link-domains#domains) for authenticating payments.

If Apple Pay does not provide a first or last name in shipping data, NEXT falls back to the customer's profile name so the checkout can continue cleanly.

</Callout>

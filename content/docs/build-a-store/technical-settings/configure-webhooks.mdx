## Webhooks

Webhooks send store events to your integration as JSON. Create them in **Settings > Webhooks** or through the [Admin API](https://developers.nextcommerce.com/docs/admin-api).

### Creating a new Webhook

1. Go to **Settings > Webhooks** and choose **Create Webhook**.
2. Enter the receiving endpoint's full URL.
3. Select the event triggers your integration needs, then save.

Events cover customers, orders, transactions, subscriptions, fulfillments, and more. Use `customer.redacted` for customer data erasure and fulfillment events for shipping updates. See the [Webhook Events reference](https://developers.nextcommerce.com/docs/webhooks#webhook-events) for the full list and payloads.

The endpoint must accept JSON and return HTTP `200` within about 20 seconds. Failed deliveries are retried. See the [developer guide](https://developers.nextcommerce.com/docs/webhooks) for signature verification, retries, and duplicate-event handling.

### How to View Webhook Logs in the Dashboard

In **Settings > Webhooks**, choose **Actions > Detail** for a webhook. The detail view shows event counts, average response time, errors, and delivery logs.

* Filter logs by date, event type, or status code.
* Use **Instance ID** to find events for a specific object, such as an order.
* Open an event to inspect its payload and delivery response.

Use **Actions > Update** to change the webhook configuration. Check the logs after correcting an endpoint error to confirm deliveries succeed.
